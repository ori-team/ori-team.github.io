# Visão — oriteam-website

## O que é

Vitrine institucional da **ori-team**: apresenta o coletivo, lista seus projetos open-source (ori-lang, oride) com páginas de detalhe derivadas dos READMEs, e lista contribuidores. Visual limpo e moderno: formas simples, tipografia leve, ícones leves.

## Escopo

- Home com logo, "o que é a ori-team" e grade de projetos (lista/thumbnail).
- Detalhe por projeto a partir do README do repositório + link externo p/ o GitHub.
- Header: `ori-team` à esquerda; nav `home · projetos · contribuidores` à direita.
- Light (bege, nunca branco puro) + dark mode.
- Sensação SPA via View Transitions; SEO preservado (MPA).

## Fora de escopo

- Documentação técnica das linguagens/ferramentas (isso vive no `ori-website` e nos repos).
- i18n (PT-BR único no lançamento), blog, busca global customizada.
- Backend, analytics, CMS.
